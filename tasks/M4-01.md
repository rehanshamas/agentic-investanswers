## Plan
Standing approval from Sham (2026-11-13); plan posted in the project thread.

1. Domain: `AgentKey` (id, owner account, name, scope `read`, key hash), `aia_agent_` prefix, name rules, at most 10 per account; `Principal.owner`; `mayWrite` (false for agents).
2. `AgentKeys`: create (key shown once), list, revoke, and the resolver (agent principal with `owner`). `AnyOfResolver` tries agent keys, then sessions.
3. Stores: memory and DynamoDB (same users table; lookup and list items written and deleted in one transaction), with a shared contract test.
4. `PlanPolicy`: an agent reads on its owner's plan.
5. Platform: `/auth/agent-keys` (POST, GET, DELETE /:id) for signed-in humans only; agents get `403 read_only`. `main.ts` uses the DynamoDB store.
6. Tests through the real server: key lifecycle, isolation between users, agent on `/bars`, `/plan` and `/live` with the owner's plan, read-only refusals.
