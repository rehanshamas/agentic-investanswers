# M2-05 Chart app: React + KLineChart, first ~500 bars, live bar, symbol and timeframe switch

GitHub issue: #22
Lane: B      Depends on: M2-03, M2-04      Owner inputs: none

## Goal
A browser chart (React + KLineChart, built-in indicators off, no TradingView libraries) that loads the newest ~500 bars of an instrument and timeframe from the History API, keeps the newest bar live over the live gateway, and lets the user switch instrument and timeframe.
